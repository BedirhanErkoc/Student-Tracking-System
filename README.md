# 📚 Student Tracking System

A lightweight, command-line (CLI) based student management application built with Python. 

This system utilizes **JSON** file handling for persistent storage, ensuring all student records are automatically saved locally and retained even after the application is closed.

## 🚀 Features

* **Add Student:** Input student details (ID Number, Full Name, Grade) and store them directly in a JSON file.
* **Persistent Storage:** Uses Python's native `json` module to sync and retain data inside `ogrenciler.json`.
* **List Students:** Display all saved student records in a clean, formatted structure.
* **Search Student:** Quick lookup by student ID number.

## 🛠️ Tech Stack & Concepts

* **Language:** Python 3
* **Data Structures:** Dictionaries & Nested Lists
* **Data Persistence:** JSON (JavaScript Object Notation) File Handling
* **Control Flow:** `while` loops, conditional branching (`if-elif-else`), exception handling (`try-except`)
